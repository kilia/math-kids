# 小孩子的作业网页

这里收小学生在浏览器里就能打开的练习页。每个练习都是一个独立的 HTML 文件，不需要安装，双击或用浏览器打开即可。

目前只有 20 以内的加减法。后面还会继续加别的作业网页，例如更多口算、以及语文、英语等练习。

## 20 以内加减法

直接打开：[https://kilia.github.io/math-kids/add_sub_20.html](https://kilia.github.io/math-kids/add_sub_20.html)

给小学生做 20 以内的加减口算。每次只出一题，两个数和计算结果都在 1 到 20 之间，不会出现 0。

- 可以选择只做加法、只做减法，或者加减随机。
- 用 0–9 的大按钮输入答案。答案是一位数时，点一下就判断；答案是两位数时，会留几秒再输入第二位。
- 答完立刻显示对错。答错时会给出正确答案，然后自动进入下一题。
- 页面统计做了多少题、对了多少、正确率和连续答对。记录保存在本机浏览器里，可以随时清零。
- 画面按 4:3 等比铺满窗口，不会出现滚动条。

用电脑或平板浏览器打开上面的链接即可开始。
